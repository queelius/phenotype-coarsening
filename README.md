# phenotype-coarsening

Paper: **Electronic phenotyping as coarsening at random: identifiability of clinical states from diagnosis codes.**

Conference-format draft (target ~12 pages including references).

## Overview

Electronic phenotyping (inferring a latent clinical state from ICD
diagnosis codes, procedure codes, and medications) is the masked-data
identifiability problem from reliability statistics: the true clinical
state = latent cause, the observed code set = candidate set, the
coding process = masking mechanism, a chart-reviewed patient =
singleton candidate set.

The crucial point: coding is informative. Sicker patients are coded
more, billing incentives shape codes, so the C2 condition
(non-informative coding) is exactly what fails. This is why code-only
prevalence estimates are biased and why chart review is a necessity.

This is the fourth paper in a series porting the masked-data
identifiability framework to new domains, after `papers/scrna-coarsening/`
(scRNA-seq zero inflation) and `papers/spatial-coarsening/` (spatial
transcriptomics deconvolution).

## Structure

- `main.tex`: top-level with preamble + section includes
- `sections/`: 8 section files, designed for ~12 pages total
  - `introduction.tex` (motivation + framework + contributions)
  - `background.tex` (brief masked-data primer)
  - `translation.tex` (the bridge + translation table)
  - `identifiability.tex` (T1 glass ceiling, T2 chart review,
    T3 code-frequency consistency)
  - `methodology.tex` (T4 bias bound under informative coding)
  - `validation.tex` (simulation + MIMIC-IV real-data plan)
  - `discussion.tex` (prior-art positioning, limitations)
  - `conclusion.tex`
- `refs.bib`: bibliography
- `figures/`: figure PDFs (generated by `scripts/figures.R`)
- `scripts/`: simulation / analysis scripts
  - `sim.R`: DGP, estimators, diagnostics (base R)
  - `run.R`: runs the four studies, writes `results.rds` (seed 20260521)
  - `figures.R`: writes `glass_ceiling.pdf`, `informative_coding.pdf`

## Prior-art honesty

Latent-class estimation of disease status without a gold standard has
a deep prior literature. Hui & Walter (1980) is the foundational
diagnostic-test latent-class model; Dawid & Skene (1979) is the
rater-error EM ancestor; eMERGE and PheKB are large phenotyping
efforts; the anchor-and-learn framework uses high-precision signals
analogous to singletons. This paper does NOT claim to invent
latent-class phenotyping. The contribution is the masked-cause /
candidate-set unification, the C1/C2/C3 classification that pinpoints
informative coding as the C2 violation, the explicit glass-ceiling
construction, and the informative-coding bias bound.
